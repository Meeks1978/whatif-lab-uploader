Privacy Policy — What If Lab Uploader

Last updated: November 23, 2026

What this application is

What If Lab Uploader is a private, single-user automation tool. It is used only by the owner of the YouTube channel "The What If Lab" to manage that owner's own channel. It is not offered to the public and has no other users.

Data accessed

With the channel owner's explicit OAuth consent, the application accesses the owner's own YouTube account through Google's official APIs to:

  • upload videos to the owner's channel (YouTube Data API v3, youtube.upload scope);
  • post comments on the owner's own videos (youtube.force-ssl scope);
  • read the owner's channel analytics (YouTube Analytics API, yt-analytics.readonly scope).

Data stored

The application stores the OAuth refresh token issued at consent on the owner's own computer, in a file readable only by the owner. No other personal data is collected, stored, sold, or shared. API responses (such as view counts) are used only to produce the owner's own channel reports.

Third parties

No data accessed through Google APIs is transferred to any third party. The application communicates only with Google's API servers.

Revoking access

The owner can revoke the application's access at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately invalidates the stored token.
